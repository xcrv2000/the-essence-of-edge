# 游戏本体

这里存放游戏实际运行代码。

当前目标是一个手机端优先、资产很轻、以 HTML 形式部署的小品级点击放置增量游戏。

当前玩家可见版本：v1.0。

## 当前文件

- `index.html`：游戏入口页面。
- `styles.css`：移动端优先的基础样式。
- `research.js`：研究列表与研究等级数据。
- `forgingFormula.js`：锻造公式、金属表与属性表；同时供独立调试工具复用。
- `battleFormula.js`：战斗公式、敌人生成与战斗结算规则；同时供独立调试工具复用。
- `bladeNaming.js`：刃命名规则；同时供独立调试工具复用。
- `main.js`：游戏逻辑入口。

## 当前状态

v1.0 是从开局到当前终点可完整走通的阶段版本，包含已解锁/待解锁分页：

- 主页：自动获得汞，通过硫矿床按钮获得硫，并显示资源、操作按钮与主页记录。
- 研究：查看开局持有研究、可研究项目、已持有研究和尚未解锁的研究。
- 冶金：研究解锁后显示；包含【冶炼】【锻造】【铭文】三个子页，其中【铭文】在后期解锁。
- 战斗：锻造出刃并研究解锁后显示；可选择 CR、手动攻击、自动战斗、磨刃、逃跑，并通过击败敌人获得盐。
- 系统：本地保存、导出导入存档码、重置存档、数据统计和里程碑。

当前正式开局系统：

- 核心资源：【汞】和【硫】。
- 主角：一团水银形的不定形生命。
- 开局研究：【汞冷凝器】，每秒自动生成 1 汞。
- 开局研究：【硫矿床】，主页按钮每次按下增加 1 硫。
- 开局限制：除此之外，主角什么都没有；冶金、战斗和铭文需要由对应研究逐步解锁。

当前研究系统：

- 开局持有：【汞冷凝器】【硫矿床】。
- 开局可研究：【汞汇聚】【硫富集】。
- 中期解锁：【汞冷凝器升级 I】【硫矿床升级 I】【汞压裂】【冶金】【更大的坩埚】【高效冶炼】【高效矿镐】【自动化矿镐】【更大的铁砧】【高效锻造】【战斗】。
- 后期解锁：【铭文】以及点击铭文页终点按钮后的三个一次性研究。
- 多等级研究按各自数据表配置价格、上限和效果；一次性研究只有 1 个等级。

当前冶金系统：

- 【冶炼】：投入汞和硫，按比例产出铅、锡、铜、铁、银、金或垃圾。
- 【锻造】：投入六种金属，按内置基底表、掺杂表、曲线参数和熵增惩罚公式产出一把刃。
- 刃拥有六种属性：【锋利、韧性、耐久、硬度、稳定、导能】，每项记录当前值和出厂最大值。
- 背包容量为 20 格；背包满时不能继续锻造。
- 背包支持查看详情、收藏、再生产、单刃删除和批量删除。

当前战斗系统：

- 击败敌人获得盐，并推进更高 CR 的可挑战范围。
- 刃会在战斗中损耗当前属性；【磨刃】可以恢复锋利但会消耗耐久。
- 自动战斗会在关键风险状态下暂停，玩家可以手动处理。
- 击败 CR5 敌人后解锁【铭文】研究。

当前终点：

- 购买【铭文】研究后解锁冶金页的【铭文】子页，并在战斗界面显示【铭文】按钮。
- 铭文页显示 v1.0 终点文本与一次性按钮【好耶！】。
- 点击【好耶！】后显示灰色 W7 轮图线索，并解锁三个后续自动资源研究。
- 里程碑中的【解锁铭文页】标记为【版本1.0终点】。
