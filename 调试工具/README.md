# 调试工具

这里存放不嵌入游戏本体的开发调试页面。

## 锻造 / 战斗公式调校器

- 入口：`forging-debug.html`
- 作用：顶部用标签切换【锻造调校】与【战斗调校】；锻造调校内继续用标签切换手动投料与随机模拟。
- 参数表：表1、表2、曲线参数、属性表现修正与高熵系数表可以在工具内临时调整，可一键重置回初始值，也可将当前设置导出到剪贴板；这些调整不写回游戏本体。
- 曲线参数：`majorExponent` 默认 2，用于将基底曲线按指数压低中比例收益；`modifierExponent` 默认 16，用于控制掺杂曲线峰值位置与衰减宽度。
- 高熵系数：按有效基底数 `effectiveN = 1 / Σ(r_i^2)` 在表内线性插值，作为最终公式中的分母项；当前默认值为 1、1、1.2、1.5、1.9、2.4。
- 校验辅助：表1右侧显示每个元素的校验和，表2右侧显示每个元素的校验积。
- 手动锻造：输出完整六属性明细，并显示六边形雷达图。
- 随机模拟：可设置总原料数量、模拟次数、每种金属的最小/最大占比（1% 步长），以及随机分配、2/3/4/5/6 属性随机模拟、单一余量填充或三金属 70% 模式；默认用于 1000 次随机锻造并返回六属性小提琴图、平均属性、属性内方差、六属性全局方差、最小值、最大值、属性总和/单项属性 Top7 榜单和样本预览。
- 筛选 Top20：随机模拟后可按属性总和或任一单项属性设置“大于 X”的筛选条件，再按属性总和或任一单项属性降序取前 20 个样本；阈值留空时表示不过滤。
- 2/3/4/5/6 属性随机模拟：每个样本会从六种金属中随机挑选对应数量的参与金属，并将总原料数量按正整数切分均匀随机分配给它们；该模式不使用比例限制区。
- 战斗调校：可从锻造结果导入刃，或在本地工具箱中新建、编辑、复制、重命名、删除、多选删除刃；支持手动攻击、自动战斗、磨刃、敌人刷新模式、四个独立 k 与裸战/维护策略寿命模拟。
- 存储：不写入游戏存档；战斗工具箱保存到浏览器 localStorage，调试日志刷新后清空。
- 公式来源：与游戏共用 `../游戏本体/forgingFormula.js`、`../游戏本体/bladeNaming.js` 与 `../游戏本体/battleFormula.js`。
