公式与参数

本工具可临时调整表1/表2；游戏本体仍使用默认表。 
baseCurve_i =
	log(14 * r_i + 1) / log(15)

major_attr =
	Σ[ baseCurve_i ^ majorExponent * baseTable[i][attr] ]

modifier_attr =
	1 + Σ[ modifierCurve_i * modifierTable[i][attr] ]

modifierCurve_i =
	(1 - r_i)^modifierExponent * (1 - (1 - r_i)^modifierExponent)

effectiveN =
	1 / Σ(r_i ^ 2)

entropy =
	interpolate(entropyPenaltyTable, effectiveN)

performance_attr =
statPerformanceTable[attr]

final_attr =
floor(major_attr * modifier_attr / entropy * performance_attr * log(totalAmount))

	// log 为十进制；高熵系数按有效基底数 effectiveN 线性插值

曲线参数

基底指数压低中比例基底收益；掺杂指数控制小比例掺杂峰值与衰减宽度。
majorExponent 大于 1 时，50%左右的投料不再轻易吃满基底；modifierExponent 越大，掺杂峰值越靠近极少量投料，且中比例衰减越快。
